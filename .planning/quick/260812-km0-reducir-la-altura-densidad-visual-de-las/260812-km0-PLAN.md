# Plan — Reducir densidad visual de las cajas en Service_Blueprint_Diagrama_Fase_5.html

## Problema

El usuario mostró la caja C2 ("Verifica tu cuenta") y pidió que las cajas del diagrama no sean tan extensas. Todas las cajas del documento comparten las mismas clases CSS (`.box`, `.copy-line`, `.format-tag`), así que un ajuste de espaciado en esas 3 reglas reduce la altura de TODAS las cajas por igual, sin tocar contenido ni estructura de grilla.

## Fix — solo CSS, un archivo

`docs/validacion/Service_Blueprint_Diagrama_Fase_5.html`, bloque `<style>`:

- `.box` (línea 176): `padding: 8px 10px` → `6px 9px`; `line-height: 1.4` → `1.32`.
- `.box strong` (línea 177): `margin-bottom: 3px` → `2px`.
- `.box + .box` (línea 178): `margin-top: 8px` → `6px` (menos separación entre cajas apiladas en la misma columna).
- `.format-tag` (línea 186): `margin: 0 0 4px` → `0 0 3px`.
- `.copy-line` (línea 197): `margin-top: 4px` → `3px`; `padding-top: 4px` → `3px`; `line-height: 1.4` → `1.32`.

No se toca `font-size` en ninguna regla (se mantiene la legibilidad), no se acorta ningún texto, no se cambia el ancho de columnas (`.sub-col`, `min-width: 236px`) para no romper la alineación de la grilla de swimlanes.

## Verificación

Abrir el archivo en el navegador y confirmar visualmente que las cajas se ven más compactas sin perder ningún texto ni romper el layout de la grilla.
